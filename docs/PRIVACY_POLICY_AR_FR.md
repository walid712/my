## العربية

في النسخة الحالية لا يطلب التطبيق إنشاء حساب، ولا يتضمن تكاملاً خلفياً لإرسال بيانات المستخدم إلى خادم تابع للتطبيق. تحفظ تفضيلات اللغة والمظهر وقوائم الوثائق المحددة محلياً بواسطة Android DataStore. مسودات الرسائل لا تُرسل تلقائياً ولا تحفظ في خادم. عند فتح الروابط، يغادر المستخدم التطبيق إلى متصفح أو تطبيق خارجي؛ وتطبق سياسة الطرف الثالث على أي بيانات يقدمها هناك.

يمكن إزالة البيانات المحلية بإزالة التطبيق. لا توجد في هذه النسخة إعلانات أو أدوات تحليل سلوكي مدمجة بحسب تبعيات المشروع وملفات المصدر التي تمت مراجعتها. قد تختلف ممارسات المتصفح أو نظام التشغيل أو تطبيقات الطرف الثالث.

إذا أضيف جمع بيانات شخصية أو حسابات أو تحليلات أو مزامنة أو تخزين سحابي، يجب تحديث هذا الإشعار، وتحديد المسؤول عن المعالجة والأساس والغرض وفترات الاحتفاظ والجهات المتلقية، واستكمال الإجراء المناسب لدى CNDP قبل التفعيل حيثما يقتضي القانون 09-08 ذلك. لا يعد هذا المستند إقراراً بأن إجراءات CNDP قد أُنجزت.

**جهة النشر / وسيلة التواصل:** لم يزود مالك المشروع بعد باسم قانوني أو عنوان دعم؛ يجب استكمالهما قبل النشر العام.

## Français

Dans la version actuelle, l’application ne demande pas de compte et n’intègre pas de backend destiné à transmettre les données des utilisateurs à un serveur exploité par l’application. Les préférences de langue et de thème ainsi que les cases de pièces cochées sont stockées localement via Android DataStore. Les brouillons ne sont pas envoyés automatiquement ni stockés sur un serveur. L’ouverture d’un lien transfère l’utilisateur vers un navigateur ou une application tierce ; la politique du tiers s’applique aux données qu’il y saisit.

Les données locales peuvent être supprimées en désinstallant l’application. Aucun module publicitaire ou d’analyse comportementale n’a été identifié dans les dépendances et sources examinées. Le navigateur, le système et les applications tierces peuvent toutefois appliquer leurs propres pratiques.

En cas d’ajout de collecte de données personnelles, de comptes, d’analytique, de synchronisation ou d’hébergement cloud, le présent avis devra être révisé, le responsable, les finalités, la base juridique, la durée de conservation et les destinataires précisés, et les formalités CNDP appropriées accomplies avant activation lorsque la loi 09-08 l’exige. Le présent document ne prétend pas que ces formalités ont déjà été accomplies.

**Éditeur / contact :** le propriétaire du projet n’a pas encore fourni de dénomination légale ni d’adresse de support ; ces informations doivent être ajoutées avant la publication publique.
