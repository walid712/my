# حالة البناء والاختبار — Mizan Maroc 1.1.0

تاريخ إعداد هذا الأرشيف: 17-11-2026.

## تحقق محلي نُفّذ فعلاً
- تجميع ملفات Kotlin الخاصة بالنماذج ومستودع البيانات باستخدام `kotlinc`: ناجح.
- تحليل ملفات XML في `app/src/main`: 13 ملفاً، كلها صالحة XML.
- تحليل ملف GitHub Actions YAML وملف metadata JSON: ناجح.
- فحص صياغة سكريبتات shell (`bash -n` و`sh -n`): ناجح.
- التحقق من وجود SHA-256 الرسمي لتوزيعة Gradle 9.3.1 وWrapper JAR في ملفات المشروع: موجود.
- التحقق من عدم وجود ملفات keystore أو كلمات مرور في الأرشيف: لا توجد.

## لم يُنفّذ في بيئة إعداد الأرشيف
- Gradle build / Android Lint / Unit Tests: لم تُشغّل؛ Gradle غير مثبت وتنزيله غير ممكن بسبب فشل DNS.
- `gradle-wrapper.jar`: غير موجود داخل الأرشيف؛ يولّده CI من Gradle 9.3.1 الرسمي ثم يتحقق منه بواسطة wrapper-validation. سكريبتات البناء المحلية تقوم بالخطوة نفسها بعد تشغيل Gradle bootstrap.
- APK وAAB: لم يتم إنتاجهما في هذه البيئة. يتوقع أن ينتجهما GitHub Actions بعد رفع المشروع وتشغيل workflow بنجاح.
- اختبارات emulator أو هاتف فعلي: لم تُنفذ لغياب Android SDK وADB وجهاز متصل. توجد خطوات آلية وقائمة اختبار يدوي في `docs/DEVICE_TEST_CHECKLIST.md`.
- Release signing: تم إعداد مسار secrets فقط؛ لم تُنشأ مفاتيح خاصة ولم تُضف أسرار إلى GitHub.

## بوابات يجب اجتيازها قبل النشر
1. نجاح CI: `lintDebug`, `testDebugUnitTest`, `assembleDebug`, `bundleDebug`.
2. نجاح `connectedDebugAndroidTest` على Emulator.
3. اختبار الهاتف الحقيقي وفق قائمة التحقق.
4. تدقيق قانوني فردي للمساطر الثماني؛ الرسوم والآجال مخفية حالياً كقيم مؤكدة، وتظهر على أنها غير متحقق منها.
5. إدخال الاسم القانوني للناشر وعنوان دعم حقيقي ونشر سياسة الخصوصية على URL عام.
6. تأكيد Application ID النهائي قبل أول رفع؛ تغييره بعد نشر التطبيق يجعله تطبيقاً مختلفاً.
7. إضافة upload key إلى GitHub Secrets بشكل آمن واختبار نسخة Release موقعة.
